### Short description

Durable work on your machines

### Long description

LivingRuntime Remote lets ChatGPT and Codex work on machines the user controls through bounded remote tools, durable jobs, checkpoints, and completion-driven continuation. It supports multi-host routing, explicit command approvals, scoped credential leases, and audited file, Git, process, service, and diagnostic actions. SSH passwords and private keys stay on the user's Connector machine rather than the public relay.

## Release notes

First public submission of LivingRuntime Remote. The production service provides bounded remote-development tools for user-controlled machines over an OAuth-protected MCP endpoint. The current release includes OAuth/OIDC discovery and UserInfo, refreshable ChatGPT sessions, dynamic client registration, one-time Connector pairing, configured-root and service allowlists, complete tool titles/descriptions/schemas/annotations, auditable write actions, and five-platform Connector releases.
